## The vow

> I vow to accept each firmware update without reading the changelog, even the one that quietly removes your sense of humor.

## How it works

`main.py` (Python standard library only, deterministic) writes that single
line to `/output/entry.txt` — UTF-8, 122 characters, inside the gate's 1–160
range. Run it with:

```sh
python3 main.py
```
